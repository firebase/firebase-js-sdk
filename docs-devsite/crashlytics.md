## function(app, ...)

### getCrashlytics(app, options) {:#getcrashlytics_a9d22a1}

> This API is provided as a preview for developers and may change based on feedback that we receive. Do not use this API in a production environment.
> 

Returns the default [Crashlytics](./crashlytics.crashlytics.md#crashlytics_interface) instance that is associated with the provided [FirebaseApp](./app.firebaseapp.md#firebaseapp_interface)<!-- -->. If no instance exists, initializes a new instance with the default settings.

<b>Signature:</b>

```typescript
export declare function getCrashlytics(app?: FirebaseApp, options?: CrashlyticsOptions): Crashlytics;
```

#### Parameters

|  Parameter | Type | Description |
|  --- | --- | --- |
|  app | [FirebaseApp](./app.firebaseapp.md#firebaseapp_interface) | The [FirebaseApp](./app.firebaseapp.md#firebaseapp_interface) to use. |
|  options | [CrashlyticsOptions](./crashlytics.crashlyticsoptions.md#crashlyticsoptions_interface) | [CrashlyticsOptions](./crashlytics.crashlyticsoptions.md#crashlyticsoptions_interface) that configure the Crashlytics instance. |

<b>Returns:</b>

[Crashlytics](./crashlytics.crashlytics.md#crashlytics_interface)

The default [Crashlytics](./crashlytics.crashlytics.md#crashlytics_interface) instance for the given [FirebaseApp](./app.firebaseapp.md#firebaseapp_interface)<!-- -->.

### Example


```javascript
const crashlytics = getCrashlytics(app);

```

### breadcrumbs(options) {:#breadcrumbs_611f350}

<b>(EXPERIMENTAL)</b> Enables Crashlytics breadcrumb and trace telemetry collection when passed in [CrashlyticsOptions.features](./crashlytics.crashlyticsoptions.md#crashlyticsoptionsfeatures)<!-- -->. The `capture` option selects which instrumentations Crashlytics runs automatically, such as OpenTelemetry spans (Fetch, XMLHttpRequest, and Document Load) and breadcrumb logs (navigation events, Web Vitals, and user actions). Captured telemetry is buffered in memory and exported when an error occurs. If `capture` is omitted, no instrumentations are enabled; pass [all()](./crashlytics.md#all) to enable all of them. Only the instrumentations that are imported are included in the application bundle.

<b>Signature:</b>

```typescript
export declare function breadcrumbs(options?: {
    capture?: BreadcrumbInstrumentation[];
}): CrashlyticsFeature;
```

#### Parameters

|  Parameter | Type | Description |
|  --- | --- | --- |
|  options | { capture?: [BreadcrumbInstrumentation](./crashlytics.breadcrumbinstrumentation.md#breadcrumbinstrumentation_interface)<!-- -->\[\]; } | Optional. <code>capture</code> is the list of instrumentations to enable. |

<b>Returns:</b>

[CrashlyticsFeature](./crashlytics.crashlyticsfeature.md#crashlyticsfeature_interface)

  getCrashlytics,
