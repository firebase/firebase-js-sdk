## QueryInsertOptions.defaultToNull

Controls how omitted columns in \*\*bulk array\*\* inserts are populated by PostgreSQL.

Only affects array inputs (single-object `insert({...})` never sets `?columns=...` and always uses PostgreSQL column `DEFAULT` expressions for omitted keys). When inserting an array of objects, the SDK sets `?columns="..."` to the `Object.keys(...)` union across all elements: - `true` (default): Omitted keys (or keys explicitly set to `undefined`<!-- -->, which `Object.keys` includes in `?columns` while `JSON.stringify` strips from the body) are inserted as `NULL`<!-- -->. - `false`<!-- -->: Appends `Prefer: missing=default` so PostgreSQL applies each column's schema `DEFAULT` expression instead of `NULL`<!-- -->.

<b>Signature:</b>

```typescript
defaultToNull?: boolean | undefined;
```

### Example

\*\*Preserve PostgreSQL column `DEFAULT` expressions on sparse bulk inserts\*\*

```ts
import type { QueryInsertOptions } from 'firebase/sql';

const insertOpts: QueryInsertOptions = { defaultToNull: false, count: 'exact' };
const res = await sql.from('events').insert(
  [
    { code: 'EVT-1', title: 'Keynote', schedule: '[2026-10-15T09:00:00Z,2026-10-15T10:00:00Z)' },
    { code: 'EVT-2', title: 'Workshop', status: 'published', schedule: '[2026-10-15T11:00:00Z,2026-10-15T13:00:00Z)' }
  ],
  insertOpts
);

```
